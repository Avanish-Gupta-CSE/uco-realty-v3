# Reference data

- `zones.json` : the 49 UCO Bank Zonal Offices, as published on the bank's website
  (https://uco.bank.in/appellate-authorities, "as on 05-02-2026"), with the spellings "Bhubaneswar" and "Vijayawada" taken from the bank's contact page (https://uco.bank.in/contact-us).
- `districts.json` : states / union territories and their districts, generated by
  `scripts/build_geo_districts.py` from the India Post "All India Pincode Directory"
  (Ministry of Communications, Department of Posts, via data.gov.in, Government Open Data Licence - India).
  Only state and district names are kept. No pincodes are stored.

Both files are read at start-up. To update them, edit the file (or re-run the script) and rebuild.
Makers can always type a district/city that is not in the list.
